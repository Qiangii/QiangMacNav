## 启动台与站点排序

- 启动台总览、从桌面或 Dock 打开的分类、网站导航窗口，现在共用同一分类的站点顺序。在任一入口调整后，刷新页面或在另一台设备登录同一账号，都能看到保存的顺序。总览中不同分类图标的穿插位置仍按账号保存在当前浏览器。
- 可用鼠标拖动、触屏长按或键盘排列自己的图标。拖到分页边缘稍停即可翻页，松手后图标从当前位置平滑落位。「设置 → 外观壁纸 → 拖拽时显示定位网格」也适用于启动台。
- 搜索结果禁止拖拽，清空搜索即可恢复排序。自己共享出去的分类仍可调整，其他人共享的分类和站点保持只读。若另一处已修改分类顺序，保存时会提示冲突并重新读取列表。

## 移动端与触屏

- 网站导航和系统设置的窄屏侧栏可用左下角按钮展开。按钮随侧栏移动，长分类名在收展时会被裁剪。在「标识」排序模式下，展开后即可使用分类拖拽手柄。
- 从桌面图标打开网站后，返回并轻点空白处或其他控件即可清除选中背景。Dock 固定图标支持短按打开、短滑滚动和长按排序。
- 触屏点按按钮、链接、菜单和图标时去除了原生蓝色高亮。鼠标悬停和键盘焦点提示独立显示。窄屏导航中的加号按钮也可由辅助技术识别为「添加网站」。

## 搜索与桌面动效

- Dock 搜索的「最近访问」和搜索结果使用随主题变化的浅色高亮，鼠标移出即清除。方向键可定位结果，回车打开网站。
- 修复打开搜索弹窗或启动台时，在 Edge 标签栏移动鼠标导致页面顶部出现黑色横带的问题。关闭浮层时遮罩原位淡出，桌面同步恢复清晰。启动台右上角的关闭按钮只显示 X，并保留原有触控区域。

## 升级方式

- **在线升级**　管理员可在「设置 → 系统更新」检查更新并安装 v1.0.5，完成后刷新页面。
- **离线升级**　支持上传安装包的部署可下载与服务器架构匹配的 `navigation-linux-amd64.tar.gz` 或 `navigation-linux-arm64.tar.gz`，在系统更新页选择「上传安装包升级」。
- **Docker 部署**　使用 `ghcr.io/qiangii/qiangmacnav:v1.0.5` 或 `qiangiii/qiangmacnav:v1.0.5` 重建容器，沿用原 `/data` 挂载、端口和环境配置。
- **浏览器插件**　使用本地加载方式的用户可下载 `qiangmacnav-extension.zip`，解压覆盖原插件目录，再到扩展管理页重新加载。
