## 系统更新

- **支持离线上传安装包。** 管理员在「系统设置 → 系统更新」点击「上传安装包升级」，选择电脑上与设备架构相符的 `.tar.gz`，确认后即可安装。群晖无需先连接 GitHub 检查版本。上传接口在服务端验证管理员身份。
- 本地上传跳过发布清单的 SHA-256 比对。启动器检查压缩包结构和程序架构，备份数据库后启动新版。只有网站报告更高版本并通过健康检查，升级才会完成。在线下载仍校验官方 SHA-256。
- **升级失败后可以重试。** 下载中断等错误现在显示在升级按钮下方。重新进入「系统更新」或重新检查到版本后，旧错误会清除。移除了按钮下方的安装包下载提示。

## 网站导航

在「应用设置 → 网站导航」中，排序选项「拖拽标识」更名为「标识」。新账号默认选中「标识」，可拖动站点或分类旁的标识调整顺序。已有账号继续使用已保存的选择。

## 群晖及 Docker 升级方式

在 v1.0.2 单容器部署中，可以通过「在线升级」将网站更新到 v1.0.3。**启用离线上传还需要更新镜像中的启动器。** 在群晖 Container Manager 拉取 `qiangiii/qiangmacnav:v1.0.3` 或 `ghcr.io/qiangii/qiangmacnav:v1.0.3`，沿用原来的 `/data` 挂载、端口和环境配置重建容器，使用镜像默认启动命令。直接重建也可以一次完成网站和启动器升级。

之后安装更高版本时，Intel 或 AMD 64 位设备选择 `navigation-linux-amd64.tar.gz`，ARM64 设备选择 `navigation-linux-arm64.tar.gz`。上传期间保持页面打开。
