## 系统更新

- **新增「安装包升级」**。管理员检查到新版本后，可以在电脑上下载对应的 `.tar.gz`，再通过局域网上传到群晖。容器只需从 GitHub 获取版本信息和校验清单，适合能检查更新但下载大文件容易中断的网络。
- 系统会提示当前架构需要的文件名，并在停服前核对官方 SHA-256。传错架构、版本或文件不完整时，原网站继续运行。校验通过后自动备份数据库、安装并检查新版服务，失败时沿用原有回滚流程。
- **更新说明支持 GitHub 风格的 Markdown**。在设置中展开即可阅读标题、列表、链接、表格和代码块，窄屏下长代码可以横向滚动。

## Dock 窗口交互

点击「导航」或「设置」图标时，已关闭或最小化的窗口会打开并置前。已打开的窗口若有 **超过 20%** 的面积被其他窗口遮挡，点击会将它带到前台；遮挡面积为 **20% 或更少** 时点击会关闭窗口。

## 从 v1.0.0 或 v1.0.1 升级

使用单容器部署时，可在「系统设置 → 系统更新」检查更新并在线升级到 v1.0.2。网页升级会更新网站和服务程序，数据库结构沿用上一版。

**要启用安装包上传，请将单容器镜像更新到 v1.0.2。** 在群晖 Container Manager 拉取 `qiangiii/qiangmacnav:v1.0.2` 或 `ghcr.io/qiangii/qiangmacnav:v1.0.2`，沿用原来的 `/data` 挂载、端口及环境配置重建容器，保留镜像默认启动命令。此方式可直接从旧版升级，也会更新启动器。

以后发现更高版本时，「在线升级」旁会出现「安装包升级」。按界面提示选择 `navigation-linux-amd64.tar.gz` 或 `navigation-linux-arm64.tar.gz`，点击「上传并升级」，并在上传期间保持页面打开。独立 updater 部署仍使用整容器镜像升级。
