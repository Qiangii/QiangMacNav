## 界面更新

- **站点图标**去掉了外层白圈。横向和纵向图片都会按原比例居中放大，设置的背景色只填充图片的透明区域。导航、桌面、Dock、启动台和搜索结果均使用新的显示方式。
- **导航卡片**支持悬停缩放。鼠标移入站点卡片时，图标在 200 毫秒内放大 10%，移出时平滑复原。开启系统「减少动态效果」后跳过动画。
- **登录日志和用户管理**改用支持分页的表格，窄屏可横向滚动。登录日志按列显示时间、登录来源、IP 和结果，展开「客户端信息」可查看完整的浏览器标识。
- **桌面搜索框**将推特的默认图标更新为透明底的黑色 X，已有账号刷新后即可看到。
- **键盘操作**调整了 F12 的行为。焦点在网页内时，页面会拦截单独按下的 F12。

## 从 v1.0.0 升级

使用支持单容器网页升级的 v1.0.0 时，请以管理员身份打开「系统设置 → 系统更新」，点击「检查更新」，再选择「在线升级」。升级完成后刷新页面，确认网站版本为 **1.0.1**。群晖 Container Manager 中的镜像标签仍显示部署时的值。

手动更新容器时，可拉取 `ghcr.io/qiangii/qiangmacnav:v1.0.1` 或 `qiangiii/qiangmacnav:v1.0.1`，沿用原来的 `/data` 挂载和端口重建容器。两个镜像均支持 Linux AMD64 和 ARM64。本版沿用 v1.0.0 的数据库结构。
