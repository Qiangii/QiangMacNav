## 桌面与导航

- 桌面上的网站和分类现在单击即可打开。按住 Ctrl、Command 或 Shift 单击可多选，拖动图标后松手只完成排列。
- 网站导航中的站点和分类菜单会显示当前可执行的操作。选择「添加到桌面」后，再打开菜单即可选择「从桌面移除」。移除快捷方式会保留导航中的原网站或分类。
- 删除站点或分类、移除桌面快捷方式、取消 Dock 固定时，图标会从原位碎散淡出。批量移除时，每个图标各自在原位播放动效。添加到桌面或固定到 Dock 时，碎片会在新位置聚合成图标。启用系统「减少动态效果」后直接显示结果。

## 操作提示

- 修复「网站已升级，请刷新页面」反复出现的问题。成功提示和刷新按钮只在本次查看期间观察到升级完成时出现。离开后再回来，会重新显示当前版本、进行中的升级或需要处理的恢复状态。
- 切换设置分类、切换窗口、最小化或关闭弹窗时会清除临时提示。离开页面后才返回的保存结果或登录错误，也不会出现在新界面。头像、图片选择器和嵌套确认框采用相同规则。
- 浏览器插件的收藏窗口也会在切换分类或离开窗口后清除旧提示，保留已填写的收藏草稿。

## 升级方式

- **网站**：管理员可在「设置 → 系统更新」检查并在线升级。使用支持本地上传的启动器时，也可下载对应架构的 `navigation-linux-amd64.tar.gz` 或 `navigation-linux-arm64.tar.gz`，通过「上传安装包升级」安装。
- **Docker 部署**：可使用 `ghcr.io/qiangii/qiangmacnav:v1.0.4` 或 `qiangiii/qiangmacnav:v1.0.4` 重建容器，沿用原 `/data` 挂载、端口和环境配置。
- **浏览器插件**：插件单独更新。使用本地加载方式的用户可下载 `qiangmacnav-extension.zip`，解压覆盖原插件目录，再到浏览器扩展管理页重新加载。
