## 新增桌面便签

- 在桌面空白处右键选择「新建便签」。标题同步到桌面图标，窗口支持拖动标题栏以及四边、四角缩放。
- 正文可在富文本与 Markdown 之间切换，支持预览、文字颜色和文字背景色。粘贴或上传的图片可与文字排在同一行，拖动图片任一边即可按比例调整大小。
- 便签标题、正文和图片使用 AES-256-GCM 加密存入 SQLite。服务端按账号校验访问权限。删除整条便签会一并删除其图片附件。

## 桌面与部署

- 桌面、网站导航、启动台、分类侧栏和 Dock 支持连续拖拽，顺序即时显示并在后台保存。
- 网站导航和系统设置窗口支持从四边和四角调整尺寸。
- README 补充常规部署、Docker、群晖 NAS、首次管理员防抢注及持久化备份说明。

## 升级方式

- **在线升级**。管理员可在「系统设置 → 系统更新」检查并安装新版。
- **上传安装包**。支持本地升级的部署可下载与设备架构匹配的 `navigation-linux-amd64.tar.gz` 或 `navigation-linux-arm64.tar.gz`，选择「上传安装包升级」。
- **更换 Docker 镜像**。使用 `ghcr.io/qiangii/qiangmacnav:v1.1.0` 或 `qiangiii/qiangmacnav:v1.1.0` 重建容器，沿用原端口、环境变量和 `/data` 挂载。

升级前请备份整个 `/data`。新版启动后会自动迁移原数据库，并在同一目录生成 `navigation.db.notes.key`。备份或迁移时，请将密钥与数据库一同保留。手动降级到旧版时，需要恢复升级前的数据库。
