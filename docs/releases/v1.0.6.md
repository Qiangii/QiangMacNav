## 分类内网址去重

- 新增、编辑、复制或移动网站时，如果目标分类已有相同网址，会提示「目标分类中已存在相同网址」。拖拽移动和浏览器扩展收藏也遵循这条规则。同一网址仍可分别收藏到多个分类。
- 每个账号的「未分类」也会检查重复。比如 `example.org` 和 `https://EXAMPLE.ORG:443/` 会被识别为同一网址。升级前已有的重复记录会保留，可自行整理。

## 「未分类」快捷方式

- 右键点击网站导航左下角的「未分类」，可选择「添加到桌面」或「固定到 Dock」。使用键盘时可按 Shift+F10，触屏上可点分类标题旁的操作按钮。
- 打开快捷方式即可查看当前账号尚未分组的网站。移走最后一个网站后，快捷方式仍会保留，之后添加的新网站也会出现在这里。再打开菜单即可移除快捷方式或取消固定。

## 浏览器扩展

- 收藏成功后，扩展显示 3 秒倒计时并自动关闭收藏窗口。点击「完成」可立即关闭。

## 升级方式

- **在线升级**　管理员可在「设置 → 系统更新」检查并安装 v1.0.6，完成后刷新页面。
- **离线升级**　使用支持上传安装包的部署时，可下载与服务器架构匹配的 `navigation-linux-amd64.tar.gz` 或 `navigation-linux-arm64.tar.gz`，在系统更新页选择「上传安装包升级」。
- **Docker 部署**　使用 `ghcr.io/qiangii/qiangmacnav:v1.0.6` 或 `qiangiii/qiangmacnav:v1.0.6` 重建容器，沿用原 `/data` 挂载、端口和环境配置。
- **浏览器扩展**　使用本地加载方式的用户可下载 `qiangmacnav-extension.zip`，解压覆盖原扩展目录，再到浏览器扩展管理页重新加载。
