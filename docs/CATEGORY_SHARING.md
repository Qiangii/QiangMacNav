# 分类共享

管理员可在自己的分类菜单中“共享分类”或“取消共享”。共享分类连同全部站点、名称和图标对全站已登录用户可见，空分类也显示。其他用户（包括其他管理员）可浏览、搜索、固定到 Dock／桌面及调整个人侧栏顺序；内容仅所有者可编辑。

分类和站点必须具有所属用户。分类的 `shared` 字段决定共享状态，站点继承所在分类的状态，新增、修改、删除、移入和移出立即影响可见性。`PUT /api/categories/{id}/sharing` 接收 `{ "shared": true/false }`，事务中再次核对管理员身份和归属。

`server/sharing.go` 的 `visibleCategoriesSQL`、`visibleSitesSQL`、`visiblePinsSQL` 统一导航、Dock、桌面与媒体访问权限。分类／站点返回 `shared` 和 `editable`，前端所有入口使用同一份可见导航快照。共享引用可以授予对应图标的读取权限，个人媒体库的列表、修改和删除仍仅归所有者。

取消共享会隐藏其他用户的固定项和快捷方式，但保留引用，再次共享可恢复。删除源内容通过触发器清理 Dock／桌面引用，侧栏分类引用通过外键清理。侧栏顺序按用户保存，不改他人分类的位置。管理员降级会清除共享标记，重新提权不自动共享；禁用期间隐藏，重新启用后恢复有效共享。

活动页面每 5 秒同步，focus／online／visibilitychange 也触发。页面隐藏时中止请求，交互、编辑、确认、保存和拖拽期间暂停；请求取消与快照检查防止迟到响应覆盖前台写入。

用户可将当前可见的共享站点复制到自己的分类或“未分类”。副本归复制者所有，源分类撤回共享后仍可使用。若源站点使用共享者上传的图标，复制操作会将该图标一并存入复制者的图标库。

相关自动检查位于 `server/sharing_test.go`、`server/main_test.go`、媒体权限和桌面布局测试中，覆盖空分类、所有者权限、共享撤回／恢复、降级、排序隔离及删除清理。
