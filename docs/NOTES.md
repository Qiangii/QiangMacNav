# 桌面便签

在桌面空白处右键选择「新建便签」。点击桌面便签图标可重新打开。拖动标题栏可移动窗口，拖动四边或四角可调整窗口尺寸。修改标题时桌面文件名立即预览，点击「保存」或按 Ctrl/Cmd+S 持久化标题和正文。关闭未保存的便签时，可在确认弹窗中选择继续编辑或放弃修改。

富文本工具栏支持标题、粗体、列表、待办、引用、代码块和表格。可对选中文字设置文字颜色和背景色，支持预设、取色及清除颜色。切换到 Markdown 源文、预览或重新打开便签时保留颜色。两种编辑模式都可粘贴剪贴板里的图片，或用工具栏上传。图片与同行文字靠下对齐，空间不足时自动换行。富文本中将鼠标移到图片任一边，光标会提示可拖动缩放。Markdown 使用图片标题字段保存宽度。仅接受 PNG、JPEG、GIF、WebP 图片，每张最多 8 MB，每份便签最多 24 张及 32 MiB，每个账号最多使用 128 MiB 图片存储。上传图片归所属便签，删除便签同时删除其桌面图标及附件。

## 传输与部署

便签可通过 HTTP 或 HTTPS 访问。HTTP 连接上的标题、正文和图片以明文传输，HTTPS 提供传输加密。Docker 和 NAS 部署可在反向代理配置 TLS，并让代理覆盖 `X-Forwarded-Proto`。设置 `TRUST_PROXY=true` 和 `TRUSTED_PROXY_CIDRS` 时应限定为实际代理地址。

便签标题、正文和图片内容用 AES-256-GCM 加密后写入 SQLite。加密记录与所属账号、便签和字段绑定；服务器持有密钥。每个接口以已登录账号为准，其他普通账号和管理员都不能通过资源 ID 读取、上传、修改或删除别人的便签。

服务首次运行自动生成 32 字节密钥文件 `<DB_PATH>.notes.key`。Docker 默认路径是 `/data/navigation.db.notes.key`，存放在持久化数据目录。可用 `NOTE_KEY_FILE` 指向单独挂载的 32 字节原始密钥文件。密钥必须和数据库一起保留，备份时应把密钥单独妥善保管。用正确密钥恢复旧库后才能解密已有便签，已有便签时缺少密钥会阻止启动。
