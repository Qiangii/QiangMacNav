# QiangMacNav 浏览器插件

Chrome / Edge 114+（Chromium、Manifest V3）插件。使用现有导航账号登录，查看个人及管理员共享分类、按分类浏览和搜索站点，通过网页右键「收藏进导航」保存当前网页。

## 构建与安装

先部署提供 `/api/extension` 接口的 QiangMacNav 服务，并在网页完成管理员初始化或账号注册。若使用 Release 提供的插件 ZIP，解压后直接加载含 `manifest.json` 的目录即可。

在项目根目录执行：

```powershell
npm ci
npm run build:extension
```

1. Chrome 打开 `chrome://extensions`；Edge 打开 `edge://extensions`。
2. 开启「开发者模式」，选择「加载已解压的扩展程序」。
3. 选择 **`extensions/qiangmacnav/dist`**，里面应直接有 `manifest.json`。不要选择源码目录或网站根目录的 `dist`。
4. 点击插件图标，首次填写导航根地址，例如 `https://nav.example.com`，点「允许访问导航」并确认浏览器授权。点击网页右键「收藏进导航」也能完成首次配置。
5. 输入网站账号和密码登录。已保存地址且缺少访问权限时，下次点击插件图标或右键收藏会直接申请该主机权限。浏览器已授权时直接打开相应界面。

修改源码后重新构建，再在扩展管理页点「重新加载」。本插件不使用远程脚本，无需在子目录独立安装依赖；复用项目 React、账号校验、MacInput / MacTextarea 和自动填充样式。

## 使用

- **浏览导航**：登录后显示管理员 / 普通用户身份、分类及站点。搜索框搜索全部可见站点的标题、网址和备注。
- **同步**：打开插件、恢复焦点、恢复网络时同步；可见窗口每 30 秒同步，也可以手动点「同步」。导航列表不写入持久缓存。
- **右键收藏**：HTTP(S) 网页右键选择「收藏进导航」。窗口内直接编辑标题、网址、Logo 和备注；底部始终显示分类和保存按钮。选中文字后右键时，选中文字优先作为备注。
- **编辑内容**：四个字段均可修改。无图标时尝试标签页图标或 `/favicon.ico`，加载失败显示文字后备图标。描述不存在时备注留空。
- **选择分类**：默认此导航地址、此账号上次选择的分类；原分类不可用时按个人侧栏顺序选第一个可编辑分类，没有则选「未分类」。共享只读分类显示但禁止选择。管理员往自己共享分类收藏时，会提示全站已登录用户可见。
- **未登录收藏**：保留采集信息，先显示登录表单，登录后继续收藏。浏览器重启后临时采集信息失效。
- **工具栏**：依次为「收藏」「同步」「官网」「退出」。「官网」打开当前账号连接的导航网站。点击「收藏」或网页右键「收藏进导航」，窗口在来源浏览器窗口中央打开。
- **长列表**：浏览面板最高 520px，站点每批显示 30 条，向下滚动自动追加。切换分类或搜索会从头展示结果。分类选择支持键盘方向键、回车、Esc 和菜单内滚动。
- **上传 Logo**：确认或修改采集到的 Logo 链接，点右侧「上传」。插件读取此刻编辑框里的图片地址，并把图片存入当前账号的图标库。首次读取该主机时，浏览器可能要求授权。上传成功后，编辑框自动换成网站返回的 `/api/media/<id>`；失败时保留原链接。支持 8 MB 以内的 PNG、JPEG、WebP、GIF，以及可转换为 PNG 的 ICO、SVG。点击「收藏进导航」后站点引用该图片。
- **退出**：只退出插件会话。网页「退出其他设备」、改密、管理员重置密码和禁用账号可使相关插件会话失效。

## 权限和存储

| 权限 | 用途 |
| --- | --- |
| contextMenus | 注册「收藏进导航」 |
| activeTab、scripting | 用户点击时临时读取当前页元数据，无常驻内容脚本 |
| storage | 导航地址、独立登录令牌、按账号隔离的分类记忆、临时采集数据 |
| 可选 HTTP(S) 主机权限 | 连接导航时申请导航主机权限；点击 Logo「上传」时申请当前图片链接的主机权限。Chrome 主机授权覆盖同协议、同主机的端口 |

密码只用于登录请求，不存储。令牌保存在限制为 TRUSTED_CONTEXTS 的 chrome.storage.local，不经过网页脚本、内容脚本或 Chrome Sync。采集草稿使用 chrome.storage.session，浏览器重启清空，下次采集时清理超过 24 小时的数据。

## 故障排查

| 现象 | 处理 |
| --- | --- |
| 返回 HTML / 404 / 非 JSON | 更新后端，确认地址指向导航根域名 |
| Logo 上传返回 `Content-Type must be application/json` | 确认导航地址实际连接的 Go 进程或容器已更新并重启。新版 `POST /api/extension/logos` 接收带 boundary 的 multipart 表单；仅重新加载插件无法更新服务端路由 |
| 无法连接 | 检查地址、端口、HTTPS 证书、代理和访问授权 |
| 主机权限撤销 | 点击插件图标或右键收藏重新授权；有效会话可直接恢复 |
| 登录失效 | 重新登录；503 故障会保留会话 |
| 特殊页面无法收藏 | chrome://、edge://、文件页、其他扩展页面不支持；部分受保护网页仅有标签页信息 |
| 图标不显示 | 某些图标禁止外链或需要网页登录，显示文字后备图标；可编辑 Logo 地址 |
| 没有可选分类 | 他人共享分类只读；使用「未分类」，或在网页创建本人分类后同步 |
| 收藏结果未确认 | 网络中断可能发生在服务器保存后；先查看导航再重试，插件不自动重发写入 |

当前版本面向 Chromium，Firefox / Safari 尚未适配。分类管理、共享设置和用户管理通过「官网」进入导航网站完成。

接口、架构与验收步骤见 [插件开发文档](DEVELOPMENT.md)。
