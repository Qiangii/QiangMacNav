# QiangMacNav 商店提交文案

## 商店详情

名称使用 `QiangMacNav`，语言选择简体中文。名称和短描述来自插件清单。

**短描述**

同步你的 QiangMacNav 分类和站点，右键收藏当前网页。

**详细描述**

QiangMacNav 让你在浏览网页时，把值得保留的链接直接存进自己的导航站。使用前，你需要一个已部署 QiangMacNav 并支持浏览器插件的导航站，以及该站点的账号。首次打开插件，输入导航地址并允许访问，再使用已有账号登录。

在网页上点右键，选择「收藏进导航」，即可预览网页标题、网址、图标和备注。如果先选中一段文字，再通过右键收藏，这段文字会自动填入备注。你可以修改这些内容、选择自己的分类，然后保存。也可以在保存前点击 Logo 旁的「上传」，把图片存进此账号的图标库。

点开工具栏图标，就能按分类浏览个人站点和管理员共享给你的站点，也可以用标题、网址或备注搜索。点「同步」可查看导航站上的最新内容，点「官网」可回到当前连接的网站管理收藏。下次收藏时，插件会记住这个账号上次选择的分类。

## 隐私表单

Chrome 和 Edge 商店的「隐私政策 URL」填写以下公开地址：

<https://github.com/Qiangii/QiangMacNav/blob/main/extensions/qiangmacnav/PRIVACY.md>

**单一用途**　让用户从浏览器收藏当前网页，并浏览、搜索和同步自己在 QiangMacNav 导航站有权查看的收藏。

| 权限 | 可填入后台的用途说明 |
| --- | --- |
| `storage` | 在浏览器本地记住导航服务器地址、登录会话和按账号区分的分类选择。在会话存储中暂存当前网页的收藏草稿，以便登录或切换窗口后继续编辑。 |
| `contextMenus` | 在普通网页的右键菜单添加「收藏进导航」。用户选中文字后通过该菜单收藏时，将选中文字预填为备注。 |
| `activeTab` | 用户使用工具栏或右键收藏时，临时访问来源标签页，以取得当前网页的网址、标题和图标。 |
| `scripting` | 用户触发收藏时，在来源页面运行随插件打包的读取函数，提取标题、描述和图标链接，预填可编辑的收藏草稿。 |
| 可选主机权限 `https://*/*`、`http://*/*` | 每位用户自行配置导航服务器，Logo 图片也可能来自不同主机。插件在连接导航时请求该导航主机的权限，在用户点击上传外部 Logo 时按需请求图片主机权限。 |

**远程代码**　选择「否」。页面信息读取函数、界面和后台脚本均随插件打包。服务器返回导航数据和图片。

**数据用途和去向**　发布者填写数据类型和公开隐私政策时，应覆盖以下实际行为。

- 账号名、密码用于向用户配置的导航服务器登录。插件保存返回的账号资料和独立会话令牌，密码只用于当次请求。退出插件时会清除本地登录会话。
- 触发收藏时读取该页的网址、标题、描述、图标链接，以及通过右键选中的文字。草稿暂存在浏览器会话中。用户确认保存后，插件把标题、网址、图标引用、备注和分类发送到其导航服务器。收藏在该服务器上的可见范围取决于所选分类。
- 为浏览和搜索，插件从导航服务器读取该账号可见的分类与站点。显示外链图标时，浏览器会联系图片主机。用户点击图标「上传」时，插件会读取图片，再将图片上传至导航服务器的账号图标库。读取外部图片用于上传的请求省略凭据和来源网址。
- 发布公开隐私政策时，填写发布者的实际联系方式，说明用户如何删除本地信息和服务器上的收藏，并按实际运营情况说明留存、共享和有限使用情况。Chrome 后台的数据类型应核对个人标识信息（账号名）、身份验证信息、网络浏览记录（主动收藏的网址）和网站内容（标题、描述、选中文字及图片）。[Chrome 隐私表单](https://developer.chrome.com/docs/webstore/cws-dashboard-privacy) · [用户数据说明](https://developer.chrome.com/docs/webstore/program-policies/user-data-faq)

## 审核员测试说明

准备一个审核员可以通过 HTTPS 访问的演示实例，使用已启用 `/api/extension` 和 `POST /api/extension/logos` 的后端。为普通测试账号建一个可写分类，放入一个可搜索的示例站点。把演示根地址、测试账号和密码填入 Chrome 的 **Test instructions** 或 Edge 的 **Notes for certification** 私密字段。

1. 打开插件，填入提供的演示根地址，点击「允许访问导航」，授权后用测试账号登录。面板应显示预置分类与示例站点。
2. 打开一个普通 HTTPS 网页，选中一段文字，右键点击「收藏进导航」。确认标题和网址来自该页，备注中出现选中的文字。
3. 选择测试账号的可写分类。若要验证图标上传，可填入一个公开可访问的 PNG 链接，点击「上传」并允许访问图片主机。成功后 Logo 字段会显示以 `/api/media/` 开头的地址。
4. 点击「收藏进导航」保存。重新打开工具栏面板，点击「同步」，按标题搜索。应能找到刚保存的站点，点击后可打开原网页。
